# l10n_tool

[![CI](https://github.com/zs-dima/l10n_tool/actions/workflows/ci.yml/badge.svg)](https://github.com/zs-dima/l10n_tool/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-purple.svg)](LICENSE)

Google Sheets → ARB → Flutter gen-l10n, bridged by
[sheety_localization](https://pub.dev/packages/sheety_localization), plus the checks that keep the
authored catalog and the committed one in agreement. Generated output is committed; builds and CI
never touch Google.

## The shape

One spreadsheet per application, a tab per domain bucket, columns
`label | description | meta | <locale>…`. The application keeps:

```
packages/localization/
  lib/src/l10n/<bucket>/app_<locale>.arb   generated by the sheet
  lib/src/generated/…                      gen-l10n output
  tool/baseline/<bucket>_<locale>.arb      the authored catalog
  credentials.json, openai.key             gitignored
```

and describes itself in a JSON file, either standalone or as an `l10n` section of a larger
identity file:

```json
{
  "sheetId": "1n9P-…",
  "locales": ["en", "ru"],
  "buckets": ["app", "errors", "settings"],
  "factualLabels": ["lang", "localeCode"]
}
```

`locales[0]` is the source language. Optional: `prefix` (`app`), `arbDir` (`lib/src/l10n`),
`baselineDir` (`tool/baseline`).

## The cycle

Run from the localization package, with `--config <file>` when the file is not `l10n_tool.json`:

```sh
dart run l10n_tool:seed_sheet      # baseline -> sheet. Destructive: rewrites every tab
dart run l10n_tool:generate --translate   # AI-fill empty cells, then generate + verify
dart run l10n_tool:generate        # sheet -> ARBs + Dart -> round-trip verification
dart run l10n_tool:verify          # the round-trip check alone
dart run l10n_tool:pull_baseline   # sheet -> source-language baseline
```

`verify` fails on a lost or drifted source key, a sheet row nobody authored, an authored
translation the machine fill overwrote, an ICU placeholder renamed in translation, or a factual
row (`lang`, `localeCode`) that still equals the source language.

## The offline gate

`verify` proves the sheet round trip. This proves the committed artefacts are self-consistent,
which is what every build compiles from:

```dart
// test/l10n_consistency_test.dart
import 'package:l10n_tool/l10n_tool.dart';
import 'package:l10n_tool/testing.dart';
import 'package:localization/localization.dart';

void main() => l10nConsistencyTests(
  L10nConfig.read('l10n_tool.json'),
  generatedLocales: Locales.values.map((l) => l.languageCode).toSet(),
);
```

## Pitfalls

- `seed_sheet` is destructive. English is edited in `tool/baseline/*_en.arb` and re-seeded;
  translations are edited in the sheet.
- Never let Sheets auto-translate a cell: it renames `{name}` to `{имя}`. The machine fill and both
  gates validate placeholders.
- Plural rows need their `meta` cell: `{"placeholders":{"count":{"type":"int"}}}`. Write each
  branch so it starts with the placeholder (`one{{count} slot}`), because the placeholder scan is
  ASCII and `=0{Notifications, …}` reads as a placeholder named `Notifications`.
